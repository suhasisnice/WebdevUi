# WebdevUi

A one-page portfolio website, made as a front-end practice project (March 2026).
Plain HTML, CSS and JavaScript, no build step.

- 3D hero title that tilts with the mouse
- Ripple buttons, tilting cards and a shimmer effect
- A draggable D3 globe that zooms in on Karnataka as you scroll
  (D3 and TopoJSON from a CDN)

## Run it

Open `index.html` in a browser. The globe needs an internet connection to load
D3 and the map data.
